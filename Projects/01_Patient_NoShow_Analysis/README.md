# Healthcare Appointment No-Show Analysis

## Project Overview
Missed healthcare appointments reduce clinic efficiency, waste provider time, and may delay care for other patients.  

This project analyzes patient appointment data to identify patterns associated with no-shows and translate those findings into actionable product and operational recommendations for healthcare scheduling systems.

## Business Problem
Healthcare organizations need to better understand:
- Which patients are more likely to miss appointments
- Whether scheduling factors, such as wait time or appointment day, influence attendance
- What interventions could help reduce no-show rates and improve appointment utilization

## Key Questions
This analysis explores:

- Which patient groups have the highest no-show rates?
- Does the time between scheduling and the appointment affect attendance?
- Are no-shows more common on certain weekdays?
- Do reminder-related variables appear associated with attendance behavior?
- What operational or product strategies may help reduce missed appointments?

## Tools Used
- **SQL** — querying and segment-level analysis
- **Python** — data cleaning, exploratory analysis, and visualization
- **Tableau** — dashboard development and stakeholder-facing reporting

## Planned Workflow
1. Clean and prepare the appointment dataset
2. Create derived features such as waiting time and appointment weekday
3. Use SQL to evaluate no-show patterns across key patient and scheduling segments
4. Build visualizations and a Tableau dashboard to communicate findings
5. Develop data-informed product and operational recommendations

## Planned Deliverables
- Cleaned dataset and feature definitions
- SQL analysis queries
- Python exploratory analysis notebook
- Tableau dashboard
- Key business insights and recommendations

## Product Analytics Focus
The goal of this project is not only to describe no-show behavior, but also to frame the analysis in a product decision-making context. Potential recommendation areas may include:

- Targeted appointment reminders
- High-risk patient outreach
- Scheduling policy adjustments
- Follow-up or confirmation workflows
- Metrics to evaluate intervention success, such as no-show rate and appointment completion rate
