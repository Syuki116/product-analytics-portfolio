# Featured Projects

## Healthcare Appointment No-show Analysis

### Business Problem
Missed healthcare appointments reduce operational efficiency
and increase costs for hospitals and clinics.

This project analyzes patient appointment behavior to identify
factors associated with no-shows and proposes operational
recommendations to improve attendance rates.

### Tools Used
- SQL
- Python
- Tableau

### Questions Explored
- Which patient groups have the highest no-show rates?
- Does waiting time affect attendance?
- Which weekdays experience more missed appointments?
- What operational strategies may reduce no-shows?

### Planned Deliverables
- SQL queries
- Tableau dashboard
- Data visualizations
- Business recommendations
